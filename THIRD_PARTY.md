# Third-party notices

ChronoSplit implements import and export compatibility with the LiveSplit
`.lss` run format and the LiveSplit One `.ls1l` layout format. This behavior was
developed for interoperability with files produced by
[LiveSplit](https://github.com/LiveSplit/LiveSplit) and
[LiveSplit One](https://github.com/LiveSplit/LiveSplitOne).

No LiveSplit or LiveSplit One source code or assets are distributed in this
repository. Their names and file formats remain associated with their
respective projects, and imported files remain the property of their owners.
ChronoSplit is not affiliated with or endorsed by either project.
